# alex-calva.github.io

Personal portfolio of Rembrandt Alexander Calva Obregón, full stack developer and data analyst.

**Live site:** https://alex-calva.github.io

Static site with no build step: HTML, CSS and vanilla JavaScript, with English and Spanish versions, light and dark themes, and a downloadable CV.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
